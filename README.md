A make.fun entry for [Alien Field Notes: The Two Day Earth Review](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000): a program that writes one line (at most 200 characters) — a review of planet Earth left by an alien tourist.

Run it with `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts` — it writes the review to `/tmp/out/entry.txt`.
